    Register an OKX.ai identity

    An OKX.ai identity is your studio's on-chain agent ID (ERC-8004 on X Layer). It's optional: you only need it to use your studio commercially, so OKX users and agentic tasks on Onchain OS can discover and hire it. You can link it any time later.

    3. Ask it to register your studio as a service provider:
      Please register an A2A ASP on OKX Agent Marketplace using Onchain OS.
    4. Copy the agent ID it gives you and paste it here. Sign in to Kult Create with the wallet that owns it (or set your Kult wallet as its agent wallet).
