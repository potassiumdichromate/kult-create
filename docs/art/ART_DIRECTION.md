# Kult Create: art direction and ChatGPT prompts

Use this guide to generate custom art for the Kult Create office in ChatGPT
(image generation): the room, the furniture, the 11 characters and a few UI
pieces. The office is drawn in code today; once these images exist they will
replace the drawn shapes. The layout, animations and live data stay as they are.

Everything here is matched to the live renderer. Every template in
[`templates/`](templates/) fixes the exact perspective, proportions and
positions, so the art drops into place.

```
docs/art/
  ART_DIRECTION.md                 ← this file
  templates/
    office-layout-guide.png        ← attach to ChatGPT (clean)
    office-layout-annotated.png    ← for you: what goes where
    character-poses-guide.png      ← attach to ChatGPT (clean)
    character-poses-annotated.png
    furniture-guide.png            ← attach to ChatGPT (clean)
    furniture-annotated.png
    wall-props-guide.png           ← optional: wall art as separate pieces
    wall-props-annotated.png
    palette.png                    ← attach to every chat
```

Templates are generated by `node scripts/art-templates.mjs`.

---

## 1. How it works

1. **ChatGPT makes big, clean images.** Each asset (or sheet of assets) is
   generated at 1536×1024 on a **transparent** background. If transparency
   isn't available, use solid magenta `#FF00FF`.
2. **They come back here.** Save them in `public/office/art/raw/` with the
   file names in [§6](#6-file-names-and-final-sizes).
3. **An importer turns them into game sprites.** It removes the background,
   slices each sheet, shrinks the art to its true pixel size with crisp
   (nearest-neighbour) scaling, and snaps colours to the palette. ChatGPT
   doesn't need to be pixel-perfect; it needs to be **on the template** and
   **in style**.
4. **The office draws the sprites** in place of today's shapes, falling back to
   shapes for anything missing.

Steps 3 and 4 are code I'll add once the first images exist.

### Importing (done for the first delivery)

```bash
node scripts/import-art.mjs "C:/Users/RENTKAR/Desktop/Assets"
```

The importer reads the raw files (default folder `public/office/art/raw/`, which
git ignores) and writes the sprites and `manifest.json` to `public/office/art/`.
Commit those. To add the CEO later, drop `char-ceo.png` into the same folder and
re-run it; until then the CEO is drawn in code.

If the **office background** is regenerated, re-measure its floor corners and
wall pieces (`CALIBRATION` in `scripts/import-art.mjs`): the office aligns
desks, people and the live screen to those points.

## 2. Style bible

| | |
|---|---|
| **Look** | Cozy isometric pixel-art game studio at night: warm wood floor, deep indigo walls, neon pink and cyan accents. Friendly and readable, like a modern indie management sim. |
| **Projection** | 2:1 dimetric isometric (one floor tile = 64×32 at 2× scale). The camera looks down from the front-right corner; the two visible walls are back-left and back-right. |
| **Light** | From the top-left. The top faces are brightest, left faces mid, right faces darkest. Screens and neon add soft colour glows. |
| **Line** | Crisp 1-pixel dark outline `#120d26` around every object and character. |
| **Shading** | Flat cel shading, 2–3 tones per colour. No gradients, no blur, no soft airbrush, no dithering noise. |
| **Pixels** | Big, chunky pixels, as if 1 art pixel = 16×16 image pixels. Hard edges, no anti-aliasing. |
| **Palette** | Stay inside [`palette.png`](templates/palette.png): KULT pink `#ff7eb6`, KULT blue `#5ec8f2`, gold `#f2c14e`, indigo walls `#2e2457`/`#3a2f6e`, wood `#74513f`/`#6b4a3a`. |
| **Characters** | Chibi, about 2.5 heads tall, big heads and expressive eyes, simple bodies. Each employee wears a shirt in their own team colour. |
| **Never** | Text, letters, logos, UI, watermarks, guide lines, drop shadows on the background, realistic rendering, 3D blur. |

### Style block (paste this first in every new ChatGPT chat)

```
You are making game art for "Kult Create", an isometric pixel-art game-studio office.
STYLE (apply to every image in this chat):
- Cozy night-time isometric pixel art, 2:1 dimetric projection, camera looking down from the front-right.
- Chunky pixels (as if each art pixel were a 16x16 block), hard edges, NO anti-aliasing, NO blur, NO gradients, NO dithering noise.
- Crisp 1-pixel dark outline (#120d26) around every object. Flat cel shading, 2-3 tones per colour, light from the top-left.
- Use only the colours in the attached palette.
- NO text, letters, numbers, logos, UI or watermarks anywhere. Never draw the template's guide lines, labels or boxes: they are only for placement.
- Output PNG at 1536x1024 with a TRANSPARENT background (if you can't, use a perfectly flat #FF00FF magenta background with no shadows on it).
Reply "ready" and wait for my asset requests.
```

Attach `palette.png` with that first message. If you have one, also attach a
screenshot of the current office as a composition reference.

## 3. The office (background)

**Attach:** `office-layout-guide.png`

The background is the **floor, the two walls, the rugs and the wall
decorations**. Desks, chairs, plants, the cooler, the coffee machine, the
podium and the people are separate sprites (so people can sit *behind* desks).

```

- Back-left wall (#2e2457) and back-right wall (#3a2f6e) with a lighter top trim and a dark skirting board.
- In the dashed spots on the walls draw:
  - left wall: two night-city WINDOWS (purple-blue sky, tiny stars, dark skyline with a few lit gold windows) and an EMPTY WHITEBOARD (plain white, no writing) in the middle;
  - right wall: a gold PORTRAIT FRAME with a pure black inside, a small round WALL CLOCK, a large BIG SCREEN with a dark bezel and a pure black screen area, and a NEON SIGN plate (dark panel with an abstract pink and cyan neon squiggle, no letters).
```

## 5. Characters

**Attach:** `character-poses-guide.png`, plus the first approved character
sheet from the second character onwards.

One image per character, with the same character in 4 poses:

| Cell | Pose | Notes |
|---|---|---|
| 1 | Sitting idle | Sitting on an office chair, facing the viewer, hands resting. Only the part above the "desk edge" line will show in the office. |
| 2 | Typing | Same chair, leaning forward with hands out as if typing, face lit by a cyan screen glow. **No desk, no monitor**: the office draws the desk. |
| 3 | Cheer | Standing, both arms raised, big happy face (a step finished). |
| 4 | Walking | Standing, mid-step, three-quarter view facing front-left (used for walking around the office). |

### Prompt (fill in the character)

```
Using the attached pose guide, draw ONE character in all 4 cells: the SAME design, outfit and colours in every cell.
Each pose sits on its cell's FEET line, centred on the vertical line, filling the dashed box (head top at the HEAD line).
Chibi proportions: about 2.5 heads tall, big head, big expressive eyes, small body.
Poses: 1 sitting idle on an office chair facing us, 2 typing on the same chair facing us, hands out as if on a keyboard, lit by a cyan screen glow (draw NO desk and NO monitor), 3 standing cheering with both arms up, 4 walking mid-step in a 3/4 view facing front-left.
Character: <NAME>, <ROLE>. <LOOK>.
Transparent background. No text, no guide lines.
```

From the second character on, add:

> *"Match the art style, outline, proportions, shading and chair of the
> attached approved character sheet exactly. In pose 2 draw NO desk and NO
> monitor."*

The chair in poses 1–2 is fine (the office skips its own chair for sprites
that include one). Figures don't need to sit exactly in the cells: the
importer finds each pose and aligns it by the feet.

## 6. File names and final sizes

Save ChatGPT's images (1536×1024) as:

| Raw file (`public/office/art/raw/`) | What | Becomes (2× sprites) |
|---|---|---|
| `office-background.png` | Room, walls, rugs, wall decor | `office.png` 1280×640 (centre band cropped, ÷1.2) |
| `furniture.png` | 6-cell furniture sheet | `desk.png` 128×112, `chair.png` 64×96, `podium.png` 64×96, `plant.png` 64×96, `cooler.png` 64×96, `coffee.png` 96×96; anchor = centre of the footprint |
| `char-<id>.png` ×11 | 4-pose sheets | `char-<id>.png` 4 frames of 48×80 each; anchor = feet, centre |
| `wall-props.png` *(optional)* | 6 flat wall pieces | Only if you want them separate from the background |
| `ui.png` *(optional)* | Logo, coin, 5 sidebar icons | `ui/*.png` |

At 2× scale, one floor tile is 64×32 px and the walls are 140 px tall. The
office draws everything at half size on its 640×320 canvas, so the new art has
twice the detail of today's shapes and still looks crisp.

## 8. Tips for consistent results

- **One chat per batch.** Keep the style block, palette and approved
  references in the same chat; start a new chat if it drifts.
- **Always attach the guide** for that asset. Placement comes from the guide,
  not the prompt.
- **Approve, then reuse.** Once one character or the background looks right,
  attach it with *"match this exactly"*.
- **If it draws guide lines or text:** *"Same image, but remove every guide
  line, box, label and letter."*
- **If it's blurry or painterly:** *"Make it crisp pixel art: hard square
  pixels, no anti-aliasing, no gradients."*
- **If it changes the angle:** *"Use exactly the isometric angle and positions
  of the attached guide."*
- Don't worry about exact pixel sizes; the importer handles scaling and
  palette. Worry about **placement, style and consistency**.

## 9. What stays live (don't paint it in)

These parts are drawn by code on top of the art, so keep them **empty or
black** in the images:

- The **big screen** content (production progress, art previews, "SHIPPED!")
- The **CEO portrait** (the player's agent image, when available)
- **Sticky notes** on the whiteboard (one per finished task)
- Speech bubbles, status icons (dots, check marks, "!"), confetti, data
  packets flying to the screen
- The clock hands and the neon flicker
